# NGA版主举报管理工具
## NGA_ReportTool
NGA玩家社区网页版版主举报信息管理增强工具。

## 特点

- **NGA 原生风格**：棕/米色配色方案，与 NGA 论坛 UI 融为一体
- **零依赖**：纯 JavaScript（ES5 兼容）
- **本地缓存**：举报数据、状态标记、筛选配置、帖子状态、关键词均存储在 localStorage
- **响应式设计**：桌面端与手机端（≤768px）均可正常使用
- **多域名支持**：覆盖 bbs.nga.cn、g.nga.cn、nga.178.com、ngabbs.com、ngacn.cc

## 功能模块

### 1. 举报列表

- **数据获取**：通过 NGA 内部 API（`__NUKE.doRequest2`）拉取版主举报信息，自动合并去重
- **表格展示**：标记、状态、举报时间、类型（主题帖/回复）、举报人、帖子标题、举报理由、版块、操作
- **标记系统**：每条举报支持三种状态 —— 未处理 / 已处理 / 已标记，点击按钮切换
- **帖子状态标签**：通过 NGA API 获取帖子/回复的状态位掩码并解码显示（隐藏、锁定、处罚、审核中、匿名、延时等 19 种状态）
- **状态筛选**：按全部 / 未处理 / 已处理 / 已标记筛选举报列表
- **关键词高亮**：举报人、帖子标题、举报理由中命中关键词时以自定义颜色高亮
- **工具栏**：刷新数据、一键完成（批量将所有未处理标记为已处理）
- **分页**：每页 25 条，支持首页/上一页/下一页/末页，减少服务器请求压力
- **统计信息**：显示举报总数、最新举报时间

### 2. 筛选版面

- **版面树**：按 ">" 分隔符构建多层级版块树形结构，支持折叠/展开
- **双模式筛选**："含子版"（匹配该版面及所有子版面）和"仅本版"（精确匹配）
- **举报计数**：每个版面旁显示该版面收到的举报数量统计
- **批量操作**：全选 / 取消全选

### 3. 关键词监测

- **关键词管理**：支持添加、删除关键词，自定义高亮背景颜色
- **启用开关**：每个关键词可独立开启/关闭（iOS 风格滑块）
- **智能匹配**：大小写不敏感，长关键词优先匹配避免短词截断
- **高亮范围**：举报人、帖子标题、举报理由三列同时生效

### 4. 设置

- **缓存管理**：显示缓存条数和最后更新时间，支持清除最旧 100 条或全部缓存
- **数据管理**：支持导出全部数据为 JSON 文件；支持覆盖导入和合并导入（按 ID 去重）

## 技术实现

| 项目 | 说明 |
|------|------|
| 数据获取 | `__NUKE.doRequest2` → `/nuke.php?__lib=noti&__act=get_all&raw=3` |
| 帖子状态 | `/read.php?pid={}&__output=11` 或 `/read.php?tid={}&__output=11`，位掩码解码 |
| 缓存键 | 举报数据 / 状态标记 / 版面筛选 / 状态筛选 / 帖子状态 / 关键词 共 6 个 localStorage Key |
| 去重 | 基于 `tid_pid_uid_timestamp` 复合键 |
| 事件 | 事件委托（表格操作、分页、筛选），Escape 关闭面板 |
| 样式 | NGA 配色（#492e1b / #fdf5e6 / #ba8b5a），CSS 以紧凑单行格式注入 |

## 使用方法

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 将 `user.js` 导入油猴脚本插件
3. 登录 NGA 后，页面右上角（或手机端导航栏）出现"举报管理"按钮，点击即可打开工具面板
