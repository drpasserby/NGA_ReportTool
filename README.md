# NGA版主举报管理工具
## NGA_ReportTool
NGA玩家社区网页版版主举报信息查看、筛选与管理增强工具。

## 特点

- **NGA 原生风格**：棕/米色配色方案 + 四套额外主题可选
- **零依赖**：纯 JavaScript（ES5 兼容），`@grant none`
- **本地缓存**：举报数据、状态标记、筛选配置、帖子状态、被举报人信息、关键词、列显隐、主题等均存储于 localStorage
- **响应式设计**：桌面端与手机端（≤768px）均可正常使用
- **多域名支持**：bbs.nga.cn / g.nga.cn / nga.178.com / ngabbs.com / ngacn.cc

## 功能模块

### 1. 举报列表

- **数据获取**：通过 NGA 内部 API（`__NUKE.doRequest2`）拉取版主举报信息，自动合并去重
- **表格展示**：标记、状态、举报时间、类型（主题帖/回复）、举报人、帖子标题、举报理由、版块、操作
- **标记系统**：每条举报支持三种状态 —— 未处理 / 已处理 / 已标记，点击按钮切换
- **帖子状态标签**：通过 NGA API 获取帖子/回复的状态位掩码并解码显示（隐藏、锁定、处罚、审核中、匿名、延时等 19 种状态）
- **状态筛选**：按全部 / 未处理 / 已处理 / 已标记筛选举报列表
- **关键词高亮**：举报人、被举报人、帖子标题、举报理由命中关键词时以自定义颜色高亮
- **帖子预览**：点击类型标签"回复"/"主题"可弹出 NGA 原生帖子预览窗口
- **工具栏**：刷新数据 / 一键完成 / 打开未处理（批量打开未处理举报链接）
- **操作下拉**：状态按钮悬停展开完成/标记/未读三个选项
- **分页**：每页 25 条，支持首页/上一页/下一页/末页

### 2. 筛选版面

- **版面树**：按 ">" 分隔符构建多层级版块树形结构，支持折叠/展开
- **双模式筛选**："含子版"和"仅本版"
- **举报计数**：每个版面旁显示举报数量统计
- **系统消息/私信**：自动归类为独立版面

### 3. 关键词监测

- 添加/删除关键词，自定义高亮颜色，独立启用/禁用开关
- 大小写不敏感，长关键词优先匹配

### 4. 设置

- **功能开关**：屏蔽系统消息、列显示管理（可隐藏任意列）
- **主题切换**：原版 / 浅彩 / 沙漠 / 迷彩 / 暗绿 五套配色
- **缓存管理**：显示条数、已用空间、最后更新时间；支持清除最旧 100 条或全部
- **数据管理**：导出 JSON / 覆盖导入 / 合并导入

## 技术实现

| 项目 | 说明 |
|------|------|
| 数据获取 | `__NUKE.doRequest2` → `/nuke.php?__lib=noti&__act=get_all&raw=3` |
| 帖子状态 | `/read.php?pid={}&__output=11` 或 `/read.php?tid={}&__output=11`，位掩码解码 |
| 被举报人 | 同一 API 响应中提取 authorid → `__U` 查找用户名 |
| 类型识别 | 主题帖(13) / 回复(14) / 系统消息(#SYSTEM#) / 私信(10) |
| 去重 | 基于 `tid_pid_uid_timestamp` 复合键 |
| 事件 | 事件委托（表格操作、分页、筛选、下拉菜单），Escape 关闭面板 |
| 主题 | CSS 覆写方式实现多主题，class 切换 |

## 使用方法

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 将 `user.js` 导入油猴脚本插件
3. 登录 NGA 后，页面右上角（或手机端导航栏）出现"举报管理"按钮，点击即可打开工具面板
